# Flow - AI Weekly Productivity Assistant

### Project Overview
Professionals spend 10+ hours weekly on manual planning, email writing, and meeting follow-ups. Flow is ONE integrated platform that automates this using AI to increase productivity.

### Features (3 Core)
1. **AI Task Planner / Scheduler (Main Feature):** Generates a prioritized Monday-Friday schedule from user goals and tasks using Eisenhower Matrix logic. Editable and copyable.
2. **Smart Email Generator:** Creates professional emails with tone control (Formal, Friendly, Persuasive). Output includes subject + body.
3. **Meeting Notes Summarizer:** Extracts Summary, Action Items (checklist), Key Decisions, and Deadlines from long notes.

### Tools Used
- Lovable AI for UI generation
- React + Tailwind CSS
- ChatGPT API for prompt engineering
- GitHub for version control

### Setup Instructions
1. Clone: `git clone https://github.com/VusumuziMasimula/AI-Weekly-Productivity-Assistant.git`
2. Install: `npm install`
3. Run: `npm run dev`
4. Open: `http://localhost:5173`

### Prompt Engineering
- **Planner Prompt:** "You are an expert productivity coach. Given TASKS: [tasks], GOALS: [goals], ENERGY: [energy], prioritize using Eisenhower Matrix and create a balanced Mon-Fri schedule with time blocks..."
- **Email Prompt:** "Act as a professional business communicator. Write a [TONE] email to [RECIPIENT] about [CONTEXT] with clear subject line..."
- **Summarizer Prompt:** "Summarize the following meeting notes and extract: 1) Summary 2) Action Items 3) Key Decisions 4) Deadlines..."

### Responsible AI Disclaimer
This application uses AI-generated content. Outputs may contain errors or bias and should be reviewed before use. No sensitive personal data is stored. Built with responsible AI principles.
